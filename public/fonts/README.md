The font is bundled unmodified under the SIL Open Font License 1.1; see OFL.txt.
It is served locally and precached for offline typing. No remote font service is used.

Tsuyig has no bundled font asset: there is no Tsuyig/Tshugyig, DDC Uchen or
Jomolhari font file in this project. The Tsuyig option uses locally installed
DDC Uchen, Jomolhari, Noto Serif Tibetan, Microsoft Himalaya or Noto Sans Tibetan.
Joyig is the final bundled fallback so Dzongkha remains readable offline even
when none of these system fonts is installed. In that case both options look
the same. A distinct Tsuyig face requires a licensed font asset before it can
be bundled; no font has been downloaded or substituted under a false name.
